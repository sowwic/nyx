    NodeComponentFlag ¶

    Bases: IntFlag

    Flags describing what a node component can do.

    Attributes:

    Name Type Description
    BUILT_IN

    created by the node type, can't be removed
    WRITABLE

    accepts input links
    READABLE

    produces output links
    EDITABLE

    value can be edited in the UI
    STATIC

    skipped during execution
    SINGLE_OUTPUT

    can be the source of one link at most
    INHERITS_DATATYPE

    datatype follows the component it takes its value from, and can be changed by the user while there is none
    INSPECTOR_HIDDEN

    not listed in the inspector
    LITERAL

    text values are kept as typed, never evaluated as an expression

    EDITABLE = enum.auto() class-attribute instance-attribute ¶
