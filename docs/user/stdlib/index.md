# Built-ins

The **stdlib** is the plugin every other plugin builds on. It provides the components, nodes and utility objects listed here, shown in the **Core** section of the nodes palette. For the rules they follow, see [How a graph executes](../execution.md); for the datatypes of their values, see [Datatypes](../datatypes.md).

| Section | Contents |
| --- | --- |
| [Nodes](nodes/index.md) | Flow control, loops, values and data, logging, the bridge. |
| [Components](components/index.md) | The plugs nodes are made of. |
| [Utility objects](util-objects/index.md) | Notes and groups. |

Other plugins add nodes of their own, for example the path nodes made from plain Python functions. They appear in their own sections of the palette.
